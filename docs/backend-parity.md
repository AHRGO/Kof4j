# Backend Parity — Kof JVM × Native × KofJS

**Last updated:** September 15, 2026
**Version:** 0.4.0-beta

> Deltas since 0.1.0: `native.risc` (riscv64) and `native.arm` (aarch64) targets separated from `native` x86_64 (**full core 02-03/09** — `NativeRiscv64E2ETest 13/13` + `NativeAarch64E2ETest 13/13` in pure asm + qemu, advanced parity pending; see `docs/development/native-multiarch.md`); Native free-list (`kof_free_head`) + `kof_gc_collect` (mark-sweep pending; auto-GC disabled); MySQL wire protocol in progress (`kof_db_mysql_scramble` + `user:pass@`); pattern matching `switch case String s` + record destructuring `Point(x,y)` on JVM/Native/JS; basic `String?` null safety; `KofScript` top-level `let` → `KofScriptGlobals`; `KofCcompiler` (`kof c`) native-only C subset; `List map/filter/reduce` + `Box<T>`; Windows SIGPIPE fix.
> Deltas 30-31/08: real `spawn`/`await` on Native (pthread + trampoline + join + thread-safe allocator futex — CONC001); real FP in XMM (FLT001); JSON objects/records + FP arrays on Native (JSN001/JSN002/JSN003); WebSocket/SSE on JVM (`app.ws`/`sse.*`, RFC 6455); `kof.http` retry/circuit JVM+JS (30s window, fail-fast); `kof.cache` 3 targets (register clobber fix); UI Phase 7 Router (real JS, JVM no-op); native SQLite via direct `.so`; `kof fmt` + `kof config gen`.
> Deltas 01/09: **`spawn` with lambda capturing external variable** (`SpawnStmt` emitted the lambda with zero captures → `VerifyError`/wrong value; now collects via `collectCaptures`); **boolean `&&`/`||` short-circuit on JS** (backend emitted bitwise `&`/`|` which evaluates both sides; now JS `&&`/`||` for `bool`, bitwise intact); **`Channel<T>` as a function parameter** (type came out with empty package and `isChannel` required `kof.concurrent` → mapped as builtin + `JvmTypeMapper` → `LinkedBlockingQueue`); **`println`/`print` before `spawn` on Native** and the pre-existing bug **`spawn→await→spawn`** (SIGSEGV in `pthread_create` — stack arrived misaligned at the C call; aligned with `andq $-16` preserving `r15` + frame); **KofJS in a real browser** (`KofJsBrowserE2ETest` — Chrome headless + HTTP + DOM); **`SECN002` closed — AES-256-GCM in KofJS** (pure JS AES-GCM: FIPS 197 key expansion + GCM CTR/GHASH, format `aesgcm$iv$ctTag` identical to JVM/Native; tamper detected by strict base64 decode `strict=true` — cross-target JVM↔JS parity tested); **`OBS002` closed — histogram/metrics on Native** (asm store 32B name+sum+count + Prometheus export via `kof_string_concat` — content parity with JVM); **`TIME001` (Native) — `time.interval`/`time.cancel`** (same mechanism as `scheduler.every`/`cancel`, SCHED001: thread per job; alias `kof_time_interval`/`kof_time_cancel` → `jmp kof_scheduler_every`/`cancel`; mutation by reference of the capture validated); **`TIME001` closed on JS (02/09) — cooperative timer queue pumped by `time.sleep`** (GraalJS has no `setInterval`; browser/Node use the native one — `KofTimeE2ETest.jsIntervalRunsPeriodicallyUntilCancelled`); **`MQ001` closed — kof.mq on Native** (pub/sub + in-process queues in asm: `.bss` store + 40B nodes, invoke-with-arg `rdi`=fn `rsi`=msg, unsubscribe by fn object identity — output parity JVM↔Native↔JS); **`Set<T>`/`Map<K,V>` as class field/return on JVM** (the `JvmTypeMapper` mapped only `List`→`ArrayList`, so `Set`/`Map` became `Lkof/Set;`/`Lkof/Map;` → `NoClassDefFoundError`; now `HashSet`/`HashMap`; + parsing of class method with generic return `Set<Int> all(` — `KofMapSetTest.setMapAsFieldAndReturn`, 3 targets); **typed ORM Query DSL (level 3, `ORM001`)** — `User.query(db){ where; orderBy; limit }` lowered to `db.query<T>` (SQL prepared at compile-time, values as binds; `KofOrmE2ETest` 22); **KofJS source map V3** (real VLQ mappings at line level: each generated function → Kof line via `KofDebugInfo` — before it was a stub `"mappings":""`; `KofJsSourceMapTest`).
> Deltas 02/09: `Set<T>` as a declared type on JVM (`kof.Set` → HashSet); JVM null-safety narrowing fixed (`s.length`/`s.substring(...)`/`if_acmp*`); `mapOf` infers the first pair; `String? s = null` prefixed parses; `readText`/`readFile` → `String?` (Native returns `null`); `size()` throws instead of `-1`; gaps `STR001`/`STR002` documented below.
> Deltas 03/09 (main): **aarch64 native core complete** (riscv→aarch64 translation, NATIVE002 13/13); **kof.deps** (package manager MVP, Maven Central); **lifecycle** `application { onStart/onShutdown }`; **W3C observability spans** (3 targets) + metrics removed; **LOG001 JS**; **TIME001 JS**.

## Principle

Kof semantics are the same on all targets. Where a target does not yet support
a feature, the compiler emits an explicit diagnostic — never code that works
differently or breaks silently.

---

## Gap convention per domain (universal view)

Every capability gap has a **diagnostic code** documented here and emitted at
compile-time. New domains follow the same pattern as the existing ones
(`SECN00x`, `CONC003`, `DB001`, `HTTP002`, ...):

| Prefix | Domain | Examples |
|---------|---------|----------|
| `HTTP`/`WEB`/`DB`/`ORM`/`MQ`/`SCHED`/`TIME`/`CONC`/`SECN` | Current systems | `HTTP002`, `WEB001`, `DB001`, `MQ001`, `SCHED001`, `CONC003`, `SECN002` |
| `AND` | Android | `AND001..004` |
| `NATIVE` | multiarch codegen | `NATIVE002` |
| `INFRA` | infrastructure / IaC | `INFRA00x` |
| `DATA` | data engineering / dataframe / ML | `DATA00x` |
| `SCI` | scientific computing / HPC | `SCI00x` |
| `BIO` | bioinformatics | `BIO00x` |
| `SECPQ` | post-quantum cryptography | `SECPQ` (target gap, never a stub) |

Rule (R6): a domain gap always has a **code + entry in this matrix** — never a
silent stub, never a weak fallback, never "partial parity" without a
diagnostic.

## Stability tiers (R5)

Each namespace/package carries a tier:

- **`stable`** — compatibility guarantee; promotes only with complete DoD
  (3 targets or diagnosed gap, E2E per target, benchmark when plausible,
  docs + `training/` synchronized, green suite).
- **`experimental`** — may change; the **official packages** layer is born
  `experimental`.

Heavy domains (`ml`, `bio`, `hpc`, `infra-<cloud>`) are **official packages**
(layer 4), **never** base stdlib (R1).
