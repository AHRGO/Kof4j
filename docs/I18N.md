# Bilingual documentation (EN / PT-BR)

Kof ships its documentation in **two languages on the same repository**. Every
document exists as a pair:

| Path | Language | Role |
|---|---|---|
| `X.md` | English | canonical, what GitHub shows, default on any machine whose locale is not Portuguese |
| `X.pt_BR.md` | Portuguese | the Portuguese front |

The first line of every document is the language switcher:

```markdown
[English](X.md) | [Português](X.pt_BR.md)
```

## How the language is selected

`scripts/docs-lang.sh` reads `LC_ALL` → `LC_MESSAGES` → `LANG` → `LANGUAGE` and
resolves the machine language: anything starting with `pt` is Portuguese;
anything else (including empty) is English.

- On a **Portuguese** machine, the versioned `post-checkout` / `post-merge`
  hook copies `X.pt_BR.md` over `X.md` and marks it `skip-worktree`, so the
  working tree shows Portuguese **and stays clean**. The committed blob is
  always the English canonical.
- On **any other** machine, the hook restores the English canonical from the
  index.
- `pre-commit` restores the canonical English before every commit, so a commit
  can never capture the Portuguese overlay by accident.
- `post-commit` re-applies the machine language afterwards.

Hooks are versioned in `.githooks/`. Enable them once per clone:

```bash
scripts/docs-lang.sh install      # sets core.hooksPath=.githooks and applies
```

## Commands

```bash
scripts/docs-lang.sh status       # machine language, coverage, pair count
scripts/docs-lang.sh check        # gate: every doc has a pair and a switcher
scripts/docs-lang.sh check --strict   # same, exit 1 on any gap
scripts/docs-lang.sh list --missing   # canonical docs still lacking PT
scripts/docs-lang.sh show README.md   # print the doc in the machine language
scripts/docs-lang.sh restore      # force the English canonical everywhere
scripts/docs-lang.sh apply pt     # force the Portuguese overlay
```

## Rules for authors

1. **Never translate inline in both files by hand and let them drift.** Edit
   the front you own; refresh the counterpart in the same commit.
2. **Keep the switcher as the first line** of every document.
3. **Internal links point to the canonical `.md`.** The hook resolves them to
   the machine language automatically; do not hardcode `.pt_BR.md` links
   except in the switcher.
4. **Code, commands, identifiers and Kof source are never translated** — only
   prose, headings and table labels.
5. A document that is not yet translated has no `.pt_BR.md` pair; `check`
   reports it as a gap until it does.
